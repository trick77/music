The iterate-until-happy loop

  1. Suggest prompt (new) — one LLM call turns the genre name into a vivid, period-correct genre image prompt (not an album cover). Live genres → a photorealistic live-gig photo; non-live genres (e.g. synthwave) → their signature aesthetic (neon 1980s). Drops it in the box; button reads “Thinking…” while it runs. Shown inside the Generate panel when both image generation and the chat key are configured.
  2. Edit — the suggestion lands in an editable textarea; tweak or rewrite it however you like (or type your own from scratch, as today).
  3. Generate — runs the existing BFL image pipeline and adds a new tile to the gallery. Not happy? Press Generate again (new seed → new variation) or “Suggest prompt” for a fresh idea, and regenerate. Variations accumulate so you can compare.
  4. Save as genre image — click the tile you like: it becomes the genre’s background (accent colour auto-resamples). Star it to also feed the Home hero.

Graceful degradation by config

  1. • BFL key set → the Generate panel appears (as today); you hand-write the prompt.
  2. • BFL + chat key → the “Suggest prompt” button also appears inside the panel (one-shot LLM).
  3. • Neither / chat only → no Generate panel at all (nothing to run an image), so no AI button either — the no-AI-in-UI invariant holds.
