Music · UI pattern proposal

One type scale, one control, one system.

A single Warm Editorial pattern to replace ~130 ad-hoc inline font sizes (≈28 distinct values) scattered across the app. Serif headings, sans body & UI, the existing dark palette — only with discipline. Every panel below is rendered on the real tokens.

Font note: this mock substitutes Georgia (serif) and the system sans, because webfonts are blocked in a shared preview. The real app keeps Anthropic Serif & Anthropic Sans — proportions and the scale hold; only the letterforms differ.

Form controls — one comfortable size

Every select / input / textarea is 40px tall with 15px UI text and a 13px label, so the box sits comfortably taller than its text. Focus into a field to see the ring.

Buttons — three variants, one size

All 40px tall, 10px radius, 15px text. The stray 8px radii and the six different button font-sizes across the app collapse into this set.

  • primary accent-strong fill · wt 600

  • small 32px · 13px
  • disabled opacity 0.6
  • busy spinner + label (no ellipsis)
The ellipsis rule. A trailing … means the command opens more UI to gather input before it acts — “Edit tags…”, “Add to playlist…”, “Replace cover…”, “New playlist…”. It is not used for actions that happen immediately (Play, Save changes, Generate), for a command that only opens a confirmation (“Delete playlist” → confirm, no …), or for busy labels (the spinner is the progress signal: “Generating”, not “Generating…”). Placeholder hints (“Search…”) are a separate, accepted idiom. Always the character … (U+2026), never three dots.

Behavior · Async

Spin while waiting · stream the answer

Two rules that apply everywhere: any pending operation shows a spinner, and LLM answers stream in — while streaming, the input is locked (no editing) and only the answer is shown (reasoning omitted). The box unlocks when the stream completes. The point is perceived speed: streaming tokens keep something visibly happening, so the wait feels shorter than a spinner staring back at an empty box.
