Editing from the mini player

A ⋯ (three-dot) menu on the docked bar opens actions for the currently-playing track — including Edit…, which opens the existing tabbed tag editor (Details / Cover / Lyrics). The menu opens upward since the bar sits at the bottom of the screen. Three options below differ only in how much the bar changes and what the menu holds. Each shows the menu open with Edit… highlighted.

Edit… → reuses the current tabbed TagEditor unchanged (full-screen on phones + iPad, so nothing gets truncated). No backend changes — it already saves to the file's ID3 tags.
